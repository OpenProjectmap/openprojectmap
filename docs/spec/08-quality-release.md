# 08: Quality, CI and release

## 1. Test layers

| Layer | Tool | What | Target |
| --- | --- | --- | --- |
| Unit | Vitest | scanner, dates, status, inline, each parser, derive, config, editor | `src/core` ≥ 95% lines, `src/node` ≥ 85% |
| Property | fast-check | the scanner never throws and positions are monotonic; for valid dates `start ≤ end`; editor round-trip | 1k cases per PR, 1M nightly (v1.0) |
| Fixture | Vitest | `test/fixtures/<case>/` docs → `expected.json` + `expected-diagnostics.txt` | one fixture per diagnostic code |
| Render | Vitest + happy-dom | views render from fixtures; `safeHref` and `rich` tables | |
| XSS | Playwright | spec 07 §2 corpus over every field | 0 executions |
| E2E | Playwright | build tidepool, open `file://`, navigate tabs, filters, theme toggle | |
| A11y | @axe-core/playwright | every view, light and dark | 0 serious/critical |
| Visual | Playwright screenshots | tidepool light, dark and 360 px | reviewed diffs |
| CLI | Vitest + `execa` (dev dep) | exit codes, output formats, `--now` determinism | |

### Fixture layout

```
test/fixtures/
  tidepool/                       → symlink-free copy of examples/tidepool
  stress-1000/                    → generated by test/gen-stress.mjs (seeded)
  diagnostics/OPM-W301/ROADMAP.md
  diagnostics/OPM-W301/expected-diagnostics.txt
  …
```

`expected-diagnostics.txt` holds one line per diagnostic in the text format (without colour), so
reviews read like CLI output. `pnpm test -u` updates the snapshots; CI never updates them.

Determinism: all tests pass `now: new Date('2026-11-16T00:00:00Z')`; git facts come from a fake
git layer injected into `buildProject` (`git: FakeGit`), except one integration test that creates a
temporary repo with fixed `GIT_COMMITTER_DATE`.

## 2. CI workflow (`.github/workflows/ci.yml`)

```yaml
name: CI
on: { push: { branches: [main, beta] }, pull_request: {} }
permissions: { contents: read }
jobs:
  test:
    strategy:
      fail-fast: false
      # full matrix on PRs to main and pushes to main; one ubuntu / Node 22 leg elsewhere (cost)
      matrix: { os: [ubuntu-latest, macos-latest, windows-latest], node: [20, 22] }
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@<sha>
        with: { fetch-depth: 0 }
      - uses: pnpm/action-setup@<sha>
      - uses: actions/setup-node@<sha>
        with: { node-version: '${{ matrix.node }}', cache: pnpm }
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm test -- --coverage
      - run: pnpm build
      - run: node dist/cli.js check --strict              # dogfood (from v0.1)
      - run: node dist/cli.js build -C examples/tidepool --now 2026-11-16
  browser:                                              # from v0.2
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@<sha>
      - uses: pnpm/action-setup@<sha>
      - uses: actions/setup-node@<sha>
        with: { node-version: 22, cache: pnpm }
      - run: pnpm install --frozen-lockfile && pnpm build
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm test:e2e                              # e2e + xss + axe + visual
      - run: node scripts/size-budget.mjs               # gz(template+client) ≤ 60 KB
      - run: npm pack --dry-run --json > pack.json && node scripts/check-pack.mjs pack.json
```

## 3. Lint rules that matter

- `no-restricted-imports` in `src/core/**`: `node:*`, `fs`, `path`, `child_process`, `process`.
- `no-restricted-properties` / `no-restricted-syntax` in `src/render/client/**`: `innerHTML`,
  `outerHTML`, `insertAdjacentHTML`, `document.write`, `eval`, `Function`.
- `no-restricted-globals` in `src/core/**`: `Date.now` via a custom rule, plus `process` and `window`.
- `@typescript-eslint/no-floating-promises`, `consistent-type-imports`.

## 4. Size and performance checks

- `scripts/size-budget.mjs`: gzip size of `CLIENT_JS + STYLES_CSS + TEMPLATE_HTML` ≤ 60 KB.
- `scripts/bench.mjs` (non-blocking job): build time on `stress-1000`, which must stay under 1 s on
  the CI runner; regressions over 20% are flagged in the PR summary.

## 5. Release process

- **SemVer.** 0.x minors may break; patch = fixes only. From 1.0: format v1, config v1, ProjectData
  v1, CLI flags and exit codes are covered.
- **Branching**: two protected environments, `beta` (preview) and `main` (production). Work
  branches `<deliverable-id>/<slug>` are cut from `beta` and squash-merged into it. `main` only
  receives a release PR from `beta`, once a version is complete, merged with a merge commit
  (decision D19).
- **Cutting `vX.Y.Z`:**
  1. Finish and test the version on `beta`. Open a PR from `beta` to `main` titled
     `vX.Y.Z — <Version title>` that:
     - moves `## [Unreleased]` items to `## [X.Y.Z] - <date>` in CHANGELOG.md,
     - sets the roadmap version's deliverables to `done`/`parked`, adds a final status line, and
       sets `**State:** shipped` (optional, since the changelog already implies it),
     - updates the Now block (Current version → the next version, Next step, Updated),
     - bumps `package.json` version.
  2. CI green, including `check --strict`.
  3. Merge with a merge commit, then tag `vX.Y.Z` on the `main` merge commit.
  4. `.github/workflows/release.yml` (on tag): builds, runs tests, `npm publish --provenance --access public`
     via trusted publishing, creates a GitHub Release with the changelog section, builds and pushes
     the Docker image (from 0.5), and redeploys the demo map to Pages.
  5. For the Action repo, move the major tag (`v1`) after testing.

## 6. Definition of Done (each version)

- [ ] Every deliverable is `done` (with a ref) or `parked` with a reason in Notes.
- [ ] Exit criteria checked, with evidence in the last status line.
- [ ] CI green on all OSes; size budget and a11y pass; the security checklist (spec 07 §8) is ticked.
- [ ] Spec docs updated for any behaviour change; diagnostic catalogue in sync with `codes.ts`.
- [ ] CHANGELOG.md release entry; the roadmap Now block updated; `check --strict` clean.
- [ ] Released to npm (and Docker/Action when relevant); demo map redeployed.
- [ ] Milestone `Reached on` filled when this version completes it.
