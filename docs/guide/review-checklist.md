# Handbook review sheet

For the people reading the Founder Handbook before v0.3.0 ships. Thank you. You are the test: if
something is unclear, the handbook is wrong, not you.

Time: about an hour. Read chapters 1 to 5 in order, then try to write a roadmap for a real project of
yours using chapter 2 and `npx openprojectmap init`.

## Tell us

1. Which words did you have to look up or guess? (Write the word and the chapter.)
2. Where did you stop reading, skim, or get bored?
3. Did you finish a roadmap? How long did it take? Where did you get stuck?
4. Did `npx openprojectmap check` say something you did not understand? Paste it.
5. After reading, could you explain to a friend what a *version*, a *milestone*, a *deliverable*, a
   *decision* and the *Parked* list are? Which one is still fuzzy?
6. What would you cut? What is missing?
7. Would you keep using this next week? Why, or why not?

## About you (optional)

- Have you planned a software project before? (never / a little / often)
- Do you write code yourself, or work with an AI agent, or both?

Send your answers to the maintainer, or open an issue titled "Handbook review: <your name or
handle>". No personal details are needed.
