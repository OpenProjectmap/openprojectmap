# 5. Mistakes everyone makes

| Mistake | Symptom | Fix |
| --- | --- | --- |
| **Everything is in v1.0** | One giant version that never ships | Ask "what's the smallest thing that tests the idea?" Make that v0.1, then slice the rest |
| **No exit criteria** | A version that is "almost done" for weeks | Write measurable exits before you start a version |
| **Status lives in chat** | The agent forgets; you forget; the map is wrong | Do the 5-minute close-out every session |
| **Zombie deliverables** | Rows in `doing` for a month | Each week, every `doing` row either moves, becomes `blocked` with a reason, or gets `parked` |
| **Silent scope creep** | Work in the diff that isn't on the roadmap | New idea → Parked or a future version, first |
| **Dates in several places** | A timeline that contradicts the text | Dates live only on the `**Window:**` line |
| **Deleting history** | No record of why things changed | Never delete status lines or rows; mark them `parked` and add a status line |
| **Reusing IDs** | Links and PR titles point to the wrong thing | IDs are forever; take the next number |
| **Decisions without defaults** | Work blocked waiting on you | Every question gets a default and a needed-by date |
| **Milestones as features** | "M2: Dark mode" | A milestone is a change in your situation ("1,000 users"), not a feature |
| **Planning a year in detail** | Plans that are wrong after 3 weeks | Detail up to the next milestone; titles and quarters beyond |
| **"Done" without verification** | Bugs found by users | `done` means tested and deployed; use `review` until then |
| **A Now block from last month** | Nobody trusts the map | Update `**Updated:**` every session; the map shows a stale banner after 14 days |
| **Publishing a private plan** | Your strategy on a public page | GitHub Pages is public on free plans; self-host behind a password for private maps ([how](self-hosting.md)) |
